MAB PORTFOLIO SITE
==================

Open index.html locally to preview the portfolio.
Keep the assets folder beside index.html; the demo and document links use relative paths.

To make a public resume-ready URL:
1. Upload the contents of this folder to a GitHub repository.
2. Enable GitHub Pages for the repository (Settings -> Pages -> deploy from main branch / root).
3. Use the resulting https://<username>.github.io/<repository>/ URL in your resume.

This is an independent concept project. The site explicitly states it is not an official Spotify product, partnership or endorsement.
